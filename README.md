# 42 Common Core

The projects from the 42 curriculum I'm proudest of (or the ones that hurt the most).

## C

| Project | What it is |
|---|---|
| [Ft_printf](CommonCore/C/Ft_printf) | `printf` rebuilt from scratch with variadic arguments |
| [Pipex](CommonCore/C/Pipex) | Shell pipelines recreated with `fork()`, `pipe()`, `dup2()` and `execve()` |
| [So_long](CommonCore/C/So_long) | Small 2D top-down game on the MiniLibX |
| [Cub3d](CommonCore/C/Cub3d) | Wolfenstein-style raycasting engine on the MiniLibX |

## C++

| Project | What it is |
|---|---|
| [Cpp02](CommonCore/C++/Cpp02) | Fixed-point number class, operator overloading, canonical form |
| [Cpp04](CommonCore/C++/Cpp04) | Subtype polymorphism, abstract classes and deep copies |
| [Cpp07](CommonCore/C++/Cpp07) | Function and class templates (`swap`, `max`, `iter`, `Array<T>`) |
| [Ft_irc](CommonCore/C++/Ft_irc) | IRC server in C++98, non-blocking sockets with `poll()`, channels and operator commands |

## Infra

| Project | What it is |
|---|---|
| [Inception](CommonCore/Docker/Inception) | Docker Compose stack: NGINX (TLS 1.2/1.3), WordPress and MariaDB, plus Redis, FTP, Adminer and Portainer |
